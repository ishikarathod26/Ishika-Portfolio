# Ishika Rathod - Developer Portfolio 📖✨

> An interactive desk-style 3D book portfolio showcasing my background as an aspiring Java Developer, skills, projects, academic records, and certifications.

🔗 **Live Portfolio:** [https://ishikarathod26.github.io/Ishika-Portfolio/](https://ishikarathod26.github.io/Ishika-Portfolio/)

---

## 🌟 Interactive Features

- 📖 **Interactive 3D Flipping Book**: Browse through pages like an authentic desk journal with realistic page turning, sounds, and haptic feedback.
- 💡 **Ambient Room Lighting**: Toggle between daylight and cozy dark mode with an interactive pull-cord switch.
- 🎨 **Custom Themes & Palettes**: Customize desk background themes, book cover colors, or roll random palettes with the "Surprise me" generator.
- 🧸 **Desk Stickers & Accessories**: 4 theme sets (One Piece, Workspace, Journal, Stationery) with draggable, resizable, and customizable desk stickers.
- ✏️ **Live Editable Fields & Highlighters**: Write notes, highlight text, and customize sticker layouts on your desk in real time.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/ishikarathod26/Ishika-Portfolio.git

# Navigate into directory
cd Ishika-Portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```
